# آرشیو استاتیک باریش برای GitHub Pages

محتویات این پوشه را در ریشه مخزن GitHub بارگذاری کنید؛ سپس Settings → Pages → Deploy from a branch → main → /(root) را انتخاب کنید. فایل CNAME وجود ندارد تا انتشار پیش‌فرض GitHub Pages به دامنه brsh.ir هدایت نشود. برای دامنه اختصاصی، پس از تنظیم DNS فایل CNAME را بسازید.

## ساختار
`pages/` صفحات ثابت؛ `products/`، `articles/` و `news/` صفحات جزئیات؛ `data/` داده‌های JSON؛ `assets/` فایل‌های CSS و JS.

## محدودیت‌ها
مرورگر استخراج محتوا دسترسی مستقیم به فایل‌های رسانه‌ای و دریافت کامل همه صفحات را فراهم نکرد. تصاویر اصلی و فونت اصلی در این نسخه دانلود نشده‌اند؛ به‌جای آن‌ها تصویر جعلی یا تولیدشده قرار نگرفته است. متن کامل پنج مقاله و دو خبر و جزئیات فنی محصولات ناقص است و در صفحات مربوطه اعلام شده. فرم تماس ارسال واقعی ندارد.
منبع: https://brsh.ir/
